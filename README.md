A make.fun entry for [One Line, One Laugh: Roast Your Fridge](https://make.fun/competitions/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521): one line roasting my own fridge.

## The line

> The freezer has a bag of peas from 2021. I keep it for the same reason the fridge keeps me: neither of us knows how to let go.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. The gate requires UTF-8 text of 1–200 characters, a single line. Run it with `--check` for a dry run (validates the gate and prints the tournament table) or `--self-test` to verify a round-trip write.

```sh
python3 main.py --check
python3 main.py
```
